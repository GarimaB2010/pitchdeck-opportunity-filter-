# The Pitch Deck – Opportunity Filter

## About

This project is a small proof of concept based on my review of The Pitch Deck website. One improvement I identified was making it easier for students to find opportunities that are actually relevant to them.

The goal of this prototype is to reduce the time students spend searching through opportunities by giving them simple filters and clearer information.

## What I Built

The prototype includes:

* Search for opportunities
* Filter by category
* Filter by grade
* Filter by deadline
* Filter by cost
* Sort opportunities by deadline
* Opportunity cards with important information
* Responsive design for desktop and mobile

Each opportunity also shows information such as its deadline, eligibility, location, and cost so students can quickly decide whether it is worth exploring.

## Why I Built It

When looking for opportunities, students usually have specific requirements. For example, a student may only be interested in opportunities available to their grade level or ones that have no application fee.

Instead of making students open multiple listings to find this information, I wanted to make those details easier to see and filter.

## How It Could Be Implemented

In a real version of The Pitch Deck, the filters could be connected to the existing opportunity database or API. Each opportunity would have structured information such as category, grade eligibility, deadline, location, and cost.

The website could then automatically update the results whenever a student changes a filter.

## My First 30 Days

If I were implementing this on the actual platform, I would start by building the responsive front-end and connecting it to the existing opportunity data. I would then implement the main filters and sorting, test everything on desktop and mobile, and get feedback from students.

After testing, I would use that feedback to improve the filtering experience and make sure the information displayed for each opportunity is consistent and easy to understand.

## Note

This is a proof of concept and uses sample opportunity data. It is not connected to The Pitch Deck's production database or systems.
